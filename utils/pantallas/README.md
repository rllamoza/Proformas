# Pantallas del Proyecto: Proformas Instalaciones Web App (Stitch)

Este repositorio contiene la descarga completa y detallada de todas las pantallas del proyecto Stitch **"Proformas Instalaciones Web App"** (ID: `6256314497810013108`).

Para cada una de las 19 pantallas se han extraído y organizado los siguientes recursos en su respectiva subcarpeta:
- `screenshot.png`: Imagen del pantallazo en alta resolución.
- `screen.html` / `index.html`: Código HTML original listo para previsualizar en cualquier navegador.
- `styles.css`: Estilos CSS extraídos detalladamente de los bloques `<style>`.
- `script.js`: Configuración de Tailwind y lógica JavaScript inline extraída de los bloques `<script>`.
- `metadata.json`: Metadatos técnicos (dimensiones, tipo de dispositivo, título, URLs originales).

## Sistema de Diseño (Neumorphic Precision Systems)
El proyecto utiliza un sistema de diseño neumórfico refinado especialmente calibrado para cotizaciones técnicas y de instalaciones:
- **Base Canvas / Sustrato:** `#E2E8F0`
- **Primario Corporativo:** `#1B2A49`
- **Acento / Conversión:** `#F26B21` (Naranja seguridad)
- **Tipografía:** `Inter` con soporte tabular para monedas (`S/`) y métricas técnicas.
- **Relieves:** Sombras duales calculadas a 315° (-5px, -5px luz `#FFFFFF` / 5px, 5px sombra `#94A3B8`).

Consulta el archivo completo [`design-system.md`](./design-system.md) para revisar todas las especificaciones de tokens, elevaciones, sombras y componentes.
